# 孤独少女に問いかけた

> *「傷つくぐらいなら、私は一人でいいや」*

エンジンもRPGツクールも使わず、**Python（Pygame Zero）だけで一から作り上げた**ホラー寄りの探索RPGです。
**企画・プログラム・ドット絵・マップ・シナリオ・BGM／効果音まで、全工程をたった一人で完成させました。**
高校時代の自分が「孤独」というテーマをどうしても形にしたくて、1万行を超えるコードを書き切った作品です。

---

## 自分でやり切ったこと

- **完全フルスクラッチ** — ゲームエンジンも制作ツールも一切使わず、Python + Pygame Zero のみで実装しました。
- **全工程を一人で** — 企画／プログラミング／画像（立ち絵・マップ・UI 346枚）／音響（BGM・効果音 32本）／シナリオまで、すべて自分の手で用意しました。
- **RPGの基幹システムを自前で設計・実装** — マップ移動・インベントリ・暗号パズル・敵の出現と追跡・セーブ／ロード・立ち絵会話システムを、ライブラリ任せにせず全部自分で組みました。
- **1万行を「完成品」として仕上げ切った** — 設計ドキュメントなしで巨大な状態を管理し、最後まで動くものとして世に出しました。
- **プレイヤー目線の作り込み** — 詰まった人のために、全19箇所以上のセーブポイントに対応した攻略動画まで自作しました。

技術的な洗練度よりも、**ゼロから一つの作品を完成させ切った企画力・継続力・実装力**を見てほしい一本です。

## どれだけ書いたか

| 項目 | 規模 |
|------|------|
| メインコード `RPG2.py` | **10,176行 / 約742KB の単一ファイル** |
| コメント行 | **約1,920行**（未来の自分のための覚書をびっしり残しました） |
| 自作クラス | 11個（`game` / `game2` / `game3` / `video` / `tennmetu` ほか） |
| 描画ロジック `draw()` | 単一関数で **約7,750行** |
| 画像アセット | **346枚** |
| 音源（BGM・効果音） | **32ファイル**（`bgm1`〜`bgm10`、効果音多数） |
| セーブ／ファイル入出力 | 約200箇所 |

`draw()` ひとつが7,000行を超えているのは、フレームワークに頼らず「画面に映るものすべて」を自分の手で並べたからです。
冒頭にずらりと並ぶ状態管理用の配列（`on`、`ii`、`so`、`item`、`save1`〜`save4`…）と、その一つ一つに付けた「これは何番目で何を意味するか」というコメントは、設計図を持たずに、頭の中だけで巨大な状態機械を回し切った記録です。

```python
on=[1,0,0,0,2,-1]  # 1-1アイテム欄 1-2セーブ欄 1-3テキスト欄  on[4]階数 on[3]シーン on[5]敵
ii=[...]           # ii[3]テキストの段落数 ii[14]会話中にプレイヤーを表示するか ...
```

## どんなゲームか

孤独を抱えた少女の物語を、館を探索しながら少しずつ解き明かしていく一本道のシナリオRPGです。
廊下を歩き、教室に入り、階を上がり、敵から逃げ、ロックされた扉の暗証番号を解き、セーブポイントへ辿り着く——そのすべてを、市販のツールではなく**生のPythonコードで一から実装**しました。

## 自分で組んだ主な機能

- フロアを跨ぐマップ移動（廊下／教室／大部屋／階層管理）
- アイテムの取得・所持・使用（全26スロットのインベントリ管理）
- 5桁の暗証番号を解くロック画面パズル
- 敵の出現・モーション・追跡、そしてゲームオーバー処理
- 立ち絵の表情差分つきセリフ・段落送り・スキップ機能
- 場面ごとに切り替わるBGMと効果音
- **4つのセーブスロット**と、ゲームを閉じても消えない独自セーブシステム

## 遊び方

Windows + Python 環境で動きます。

```bat
GAME.bat
```

`GAME.bat` の中身はシンプルです。

```bat
py -m pip install pgzero
py RPG2.py
```

> ※ BGM・効果音の再生に Windows の `winsound` を使っているため、Windows での実行を想定しています。
> ※ ショートカット `(←このアイコンをダブルクリックしてゲーム開始).lnk` からも起動できます。
